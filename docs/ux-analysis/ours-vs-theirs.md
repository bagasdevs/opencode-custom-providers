# Ours vs. theirs: custom-provider wizard gap table

- **OURS**: `opencode-custom-providers@1.0.1-stable` (audited at 1.0.1) (OpenCode 1 + 2). Primary files read in full: `src/tui-v2.ts` (439 lines), `src/server-v2.ts` (1055 lines); supporting: `src/tui.ts`, `src/server.ts`, `src/probe.ts`, `src/deep-probe.ts`, `src/flavors.ts`, `src/catalog.ts`, `src/v2-models.ts`, `src/reconcile.ts`, `src/commands.ts`, `src/security.ts`, `src/enrich.ts`, `src/rules.ts`.
- **THEIRS**: `better-custom-provider@1.6.0` ("better-custom", for Pi / Oh My Pi). Files read in full: `src/flows/add.ts` (307), `src/flows/edit.ts` (855), `src/ui/prompts.ts` (301), `README.md` (173); supporting: `index.ts`, `src/ui/select.ts`, `src/flows/shared.ts`, `src/flows/delete.ts`, `src/model-entry.ts`, `src/config.ts`, `src/url.ts`, `src/api-key.ts`, `src/types.ts`, `src/presets.ts`, plus the real `model-probe@0.7.0` package (`src/detect.ts`, `src/known-models.ts`, `rules.json` = 100 entries).
- **Method**: both wizards were driven end-to-end by real harnesses against real local HTTP endpoints; every claim below is backed by a logged run (see `qa-harness/logs/`). Line numbers are from the files above.
- **Blunt summary**: theirs is the more complete product for its host. Ours is more careful about not guessing and has a better beginner-facing *copy* style, but on raw capability theirs wins on per-model editing, reconcile fidelity, metadata updates, manual entry, key lifecycle, and failure recovery. Our v2 surface regressed several things our own v1 surface already had.

## Verdict

**Theirs does more; ours explains more.** If a beginner hits a real-world snag, a gateway that returns no models, a key they need to replace, a model whose context window changed, a provider they want to rename, theirs has a path and ours (on the v2 surface) often does not. The three highest-impact fixes are: make delete actually delete (#14, including the credential), make reconcile diff and apply metadata changes (#2), and stop recommending a catalog path that cannot work for Claude/OpenAI/Google/Groq/Mistral (#9). Everything in the table is backed by a real run; the artifacts are listed in `st_01a124f4-manual-qa.md`.
